# ComfyUI LoRA 分类加载

把 LoRA 按**类别**管起来：按类别勾选、同类互斥、跨类别联动，选中即在节点内完成加载；
再配一套**跟着 LoRA 走的提示词预设**，勾哪条就输出哪条。

包含两个节点 + 一个管理面板：

| | 作用 |
|---|---|
| 节点「**LoRA分类加载**」 | 按类别勾选 LoRA，加载后输出叠加好的 `MODEL`，外加名称与语法串 |
| 节点「**LoRA提示词选择**」 | 按 LoRA 分组列出预设复选框，勾选后拼成一段提示词字符串 |
| **管理面板** | 建类别、打标签（可多标签）、写提示词预设、传预览图、按文件夹自动归类 |

---

## 功能

### 「LoRA分类加载」

节点主体是一块**折叠面板**：

- **按类别分组**，每个类别可折叠；标题上带「单选 / 多选」徽章和勾选计数。
- **一个 LoRA 可以挂多个类别标签**，会同时出现在这几个类别里，行尾显示 `+N` 表示它还挂在别处。
- **勾选状态是全局的**：同一个 LoRA 在几个类别里出现，就是同一份状态 —— 在任意一处点一下，其它几处同时变成勾选 / 取消。
- **单选类别**（同类互斥）：点一个会关掉**这个类别里**原来那个；被关掉的那个如果同时挂在别的类别下，那边也会一起取消（启用状态只有一份）。
- **多选类别**：可以同时勾好几个。
- **拖拽 = 给这个 LoRA 加一个类别标签**（写回全局配置，持久保存）。拖到分类区任意位置都行，靠近面板上下边缘会自动滚动。
- 行尾的 **✕** = 把这个类别标签从该 LoRA 上摘掉（不影响勾选）。
- **每个 LoRA 一个强度**：勾上的行右侧有一个强度框，**可以直接输入，也可以按住左右拖动**（横向 100px = 1.0）。只影响当前工作流。默认 1.0，另有 `global_strength` 做整体倍率。
  只作用于 UNET 侧 —— 常见的 LoRA 对文本编码器影响可以忽略，所以没有单独的 CLIP 强度。
- 有预览图的 LoRA 名字后面有个小方框标记，**鼠标悬停浮出预览图**。
- 顶部有**搜索框**和**子文件夹过滤**。
- **选中即在本节点内完成加载**，不需要再串一个 LoraLoader。

#### 按子文件夹过滤

如果你的 LoRA 按模型分了目录（`sdxl/…`、`flux/…`），面板顶部的**子文件夹下拉**可以收窄成「只看这一个文件夹」：

- 选项来自 LoRA 相对路径的**第一层目录**，外加「全部文件夹」；如果有 LoRA 直接放在根目录，会多一个「（根目录）」。
- **选择跟着工作流保存** —— 同一个工作流打开还是上次那个文件夹，不同工作流各记各的。
- 过滤开着时，被过滤干净的类别会直接收起来，不留空壳。
- 只有**确实有 LoRA 落在子文件夹里**时这个下拉才出现。

#### 临时分类

面板底部可以新建临时分类。它**只存在当前工作流**，不写回全局配置 —— 适合「这一张图想临时凑几个 LoRA 一起上」。
把上面任意 LoRA 拖进去即可（**拖进去会顺手启用它**，但不改它的类别标签）；行尾 ✕ 移出，标题上的 ✕ 删掉整个临时分类。

#### 输入 / 输出

| 输入 | 说明 |
|---|---|
| `model` | 基础模型。**可选**：不接则不做实际加载，只输出 `LORA_NAMES` / `LORA_SYNTAX` |
| `selection` | 折叠面板自动维护的状态（JSON），平时不用管 |
| `<每个类别一个下拉>` | **降级界面**，正常情况下被隐藏，见下 |
| `global_strength` | 总强度倍率，乘以各 LoRA 自己的强度 |

| 输出 | 说明 |
|---|---|
| `MODEL` | 叠加了所选 LoRA；没接 `model` 输入时为空 |
| `LORA_NAMES` | 本次启用的 LoRA，**按加载顺序**换行分隔（接给「LoRA提示词选择」） |
| `LORA_SYNTAX` | `<lora:名称:强度>` 形式的纯文本记录 |

**不接 `model` 也能跑**：此时不往模型里叠加任何东西，但照样输出 `LORA_NAMES` / `LORA_SYNTAX`（强度取管理面板里配的值）。
只想看提示词、或只想把 `LORA_NAMES` 喂给下一个节点时，不必被迫拉一整条采样链路。

> **没接 `model` 时，面板上会有一条橙色提示**，明确写着「现在只输出名称与语法，不会真的加载 LoRA」。
> 因为这种情况下勾选和强度都不会带来任何画面变化，不给提示的话很容易误判成插件坏了。接上后提示自动消失。

**`LORA_SYNTAX` 是给人和其它工具读的记录**（A1111 / Civitai 那种写法），它**不参与生成**：

```
<lora:风格/film_like:0.85>
<lora:写实/portrait:1.00>
```

真正把 LoRA 叠进模型是节点内部用 `comfy.sd.load_lora_for_models` 做的（`clip` 传 `None`），`MODEL` 输出已经是加载好的结果。
把这一路接到「保存图片」的元数据输入，回看时就知道这张图用了哪些 LoRA、什么强度。不关心就空着不接。

**每次实际加载都会在控制台报告结果**：

```
[LoRA分类加载] 已加载 LoRA「风格/film_like.safetensors」（强度 0.85，应用 180 处权重）
[LoRA分类加载] ⚠️ LoRA「xxx.safetensors」与当前模型对不上：没有任何权重被应用，画面上不会有变化。
```

「应用 N 处权重」是实际映射到当前模型上的层数。LoRA 与基础模型不匹配时加载器**不会报错**，
它只是把匹配不到的权重丢掉 —— 一处都匹配不上时插件会明确警告，而不是让你对着没变化的图干瞪眼。

**加载顺序**：只由**库里的类别顺序 → 类别内列表顺序**决定；多标签的 LoRA 以它第一个类别的位置为准。勾选的先后**不影响**顺序，结果可复现。

**降级机制**：折叠面板是自定义前端组件。万一在当前前端渲染失败，插件会自动把隐藏的原生下拉框放出来 ——
每个类别一个下拉、单选互斥，功能完整，只是没有多标签联动、临时分类、搜索和文件夹过滤。两条通路的状态是同一份。

### 「LoRA提示词选择」

- 把上游的 `LORA_NAMES` 接进 `lora_names`。
- 节点上按 LoRA 分组，把每个 LoRA 的预设列成**复选框**（像打钩日程）。
- 每个 LoRA 单独一组「全选 / 清空」，顶部还有整体的「全选 / 全不选」。
- 输出拼好的 **`PROMPT`**，直接接文本编码节点。

| 输入 | 说明 |
|---|---|
| `lora_names` | 上游「LoRA分类加载」的 `LORA_NAMES` |
| `selection` | 复选框状态（JSON），平时不用管 |
| `separator` | 片段之间的分隔符：换行 / 双换行 / 逗号+空格 / 空格 |
| `prefix` / `suffix` | 各算**独立一段**，跟正文用同一个分隔符隔开（不是首尾硬黏）。不用就留空 |
| `dedupe` | 去掉完全重复的片段 |

| 输出 | 说明 |
|---|---|
| `PROMPT` | 勾选的提示词拼接结果 |
| `REPORT` | 本次用了哪些 LoRA 的哪些预设，排查用 |

**拼接顺序**：

1. **LoRA 之间** → 按上游的加载顺序（= 管理面板里的类别顺序）；
2. **同一个 LoRA 内** → 按管理面板里预设的排列顺序（不是勾选先后）；
3. **分隔符** → `prefix`、正文、`suffix` 用它串起来。

> **勾选改动要重新执行才会生效**：打钩只改状态，节点不会自动重跑；而「预览文本」这类节点显示的永远是**上一次执行**的结果。
> 「勾了却没变化」基本都是没重新执行 —— 按 `Ctrl+Enter` 再跑一次即可。

> **载入工作流时参数错位**：新版 ComfyUI 前端在按位置恢复节点参数时，会给 `forceInput` 的字符串输入多留一格，
> 导致节点参数整体串位（`prefix` 的值跑到 `separator` 等）。插件已内置修正（载入时按名字把每个参数重放一遍）。
> 如果你的旧工作流**在修复前**就已经存过串位后的值，`prefix` / `suffix` 是自由文本无法自动判断，打开节点**手动重填一次**即可；`separator` / `selection` 会自动复位。

### 管理面板

浏览器打开 `http://<你的 ComfyUI 地址>/lora_category_loader`，或点顶部菜单的「LoRA 分类管理」。

- **类别**：新建 / 改名 / 删除 / 拖动排序；每个类别标「单选」或「多选」。
- **LoRA 卡片网格**：搜索、按类别筛选、**按子文件夹筛选**；点图选中多张后可以批量操作。
- **多标签**：卡片上是标签 chips，用「＋ 加类别」追加、chip 上的 ✕ 摘掉；批量可以「＋ 加标签 / － 去标签 / 设为唯一」。
- **提示词预设**：每个 LoRA 可以有多条完整提示词，可增删、可排序。
- **预览图**：鼠标移到卡片图上可上传 / 更换 / 删除。
- **按文件夹自动归类**：把 `models/loras` 下的子目录名直接变成类别，已经打过标签的不会被覆盖。

> 新增 / 删除**类别**之后，需要让 ComfyUI 重新读取节点定义，节点上的下拉框才会更新：
> 点面板右上角「刷新节点定义」，或回到 ComfyUI 页面按 `R`。
> 只改标签归属、文件夹过滤、预设内容则不需要刷新。

## 安装

把整个 `ComfyUI-LoraCategoryLoader` 目录放进：

```
ComfyUI/custom_nodes/ComfyUI-LoraCategoryLoader
```

重启 ComfyUI。**不需要任何额外依赖。**

> **从 0.3.2 或更早升级上来**：这一版去掉了 `CLIP` 输入和 `CLIP` 输出，节点的输出从
> `MODEL / CLIP / LORA_NAMES / LORA_SYNTAX` 变成 `MODEL / LORA_NAMES / LORA_SYNTAX`。
> ComfyUI 的连线按**位置**存，所以打开旧工作流后 **「LoRA提示词选择」那根线要重连一次** ——
> 原来接在 `LORA_NAMES`（第 3 个输出）上的线，现在会落到 `LORA_SYNTAX` 上，拿不到 LoRA 名称。
> 把它拖到新的 `LORA_NAMES`（第 2 个输出）即可。数据文件会自动兼容，不用手动改。

## 上手流程

1. 打开管理面板，点 **「按文件夹自动归类」**，或手动建类别、拖排序、打标签。
   `models/loras` 下的子目录名会被当作类别（`loras/风格/xxx.safetensors` → 类别「风格」）。
2. 点每个 LoRA 卡片的 **「提示词预设」**，写好它的完整提示词（一个 LoRA 可以有多条）。
   顺手给卡片配张预览图，之后在加载节点里悬停就能看到。
3. 回到画布，加「LoRA分类加载」→ 接「LoRA提示词选择」→ 接文本编码。
4. 在折叠面板里勾 LoRA（想只显示某个模型目录就动一下顶部的子文件夹下拉），
   再在提示词选择节点上勾要用的预设。
5. 想临时凑一组？在面板底部新建临时分类，把 LoRA 拖进去。

## 数据存在哪

```
<ComfyUI user 目录>/lora_category_loader/library.json
```

放在 user 目录而不是插件目录，插件升级、重装、删了重下都不会丢配置。纯 UTF-8 JSON，可以直接手改，改完插件会自动检测并重载。

结构（**schema v3：类别是多标签列表**）：

```json
{
  "version": 3,
  "categories": [
    { "id": "default", "name": "未分类", "mode": "multi", "order": 0 },
    { "id": "cat1a2b3c4d", "name": "风格", "mode": "exclusive", "order": 1 },
    { "id": "cat9f8e7d6c", "name": "人物", "mode": "multi", "order": 2 }
  ],
  "loras": {
    "风格/film_like.safetensors": {
      "categories": ["cat1a2b3c4d", "cat9f8e7d6c"],
      "model_strength": 0.85,
      "notes": "",
      "presets": [
        { "id": "p1", "name": "预设一", "text": "你的提示词写在这里" },
        { "id": "p2", "name": "预设二", "text": "另一条提示词" }
      ]
    }
  }
}
```

- LoRA 的主键是**相对路径**，跟着硬盘上的实际结构走。新出现的文件会自动归到「未分类」，打上标签即可。
- 强度只有一个 `model_strength`，**默认 1.0**。早期版本多存过一个 `clip_strength`，读到会被忽略、下次保存就消失。
- **挪进子文件夹 / 改名不用重新配**：插件会按「文件名唯一匹配」把已有记录认领到新路径，标签、强度、预设、上传的预览图全都跟着走（控制台会打印 `认领：旧路径 → 新路径`）。如果两个目录下有同名文件（匹配不唯一）就**不动手**，宁可让你手动改，也好过张冠李戴。
- `version` 会自动升级：v1（默认类别单选）→ v2（默认类别多选）→ v3（类别多标签）。旧文件就地升级，**预设、强度、标签都不会丢**。
- 哪些配置跟着工作流、哪些跟着机器：**勾选状态、文件夹过滤、临时分类**随工作流；**类别、标签、强度默认值、预设、预览图**随机器。

## 预览图

**上传**：管理面板里把鼠标移到 LoRA 卡片图上，右下角出现「上传图 / 换图 / 删除」。图片存在

```
<ComfyUI user 目录>/lora_category_loader/previews/
```

只接受 PNG / JPG / WEBP / GIF / AVIF（按文件魔数判断，SVG、HTML 这类会被拒），单张上限 8MB。
上传后立刻生效：管理面板显示，加载节点里悬停对应 LoRA 也会浮出小窗。

**没上传时按顺序自动找**：

1. 本插件上传的图（优先级最高）；
2. 模型旁同名图：`<LoRA名>.preview.png` / `<LoRA名>.png`；
3. LoRA Manager 的 sidecar（`<模型名>.metadata.json`）里的 `preview_url`，没有就看 `civitai.images[].url`；
4. 常见预览图目录，如 `models/lora_previews/<相同子目录结构>/<同名>.png`。

远端图由浏览器直接加载，本插件不缓存、不下载。

## 和 ComfyUI-Lora-Manager 的关系

只做一件事：**如果 LoRA Manager 给某个 LoRA 存过预览图，本插件就把那个图读出来显示**（读它写在模型旁的 `.metadata.json` 文件格式，属于数据不是代码）。
不依赖它、不引用它一行代码，两者可以同时装、同时用；不装它也不影响本插件的任何功能。

## 已知限制

- 折叠面板是自定义前端组件。ComfyUI 新版前端（Nodes 2.0）对这类组件支持还不稳定；渲染失败时自动降级到原生下拉框（少了多标签联动、临时分类、搜索、文件夹过滤）。要完整功能可切回旧版画布（legacy canvas）。
- 拖拽是**自己实现的**（指针事件），没用浏览器原生 HTML5 拖拽（在画布上原生拖拽实测会中途断掉）。所以拖拽只在「LoRA分类加载」节点内部有效，不能把 LoRA 从别处拖进来。
- 临时分类只活在当前工作流，换工作流就没了 —— 设计如此；要长期保留就建成正式类别。
- 同一个 LoRA 挂多个标签会显示多行，但**只是一份状态**：勾一处、处处同步，加载时也只加载一次。
- 「LoRA提示词选择」读的是上游**当前的选择状态**，必须先接上 `LORA_NAMES` 才会显示内容。
- 类别数量上限 60，超过的部分不会出现在节点上（控制台会提示）。
- **类别增删后，旧工作流里的下拉框值会被安全忽略**：不会报 `Required input is missing`，也不会串到别的输入上；真正生效的始终是折叠面板写进 `selection` 的那份状态。加完类别记得点「刷新节点定义」让节点上的下拉框跟上。
- 管理面板的批量条（`＋ 加标签 / － 去标签 / 设为唯一`）要先在下拉里选中类别，否则只提示、不改数据。
- 文件夹过滤按**第一层目录**分组，更深的层级会一起归到第一层。
- `extra_model_paths.yaml` 里的额外 LoRA 目录同样能扫到。

## 自检

不需要 ComfyUI、不需要 torch，纯离线跑：

```bash
python tests/selftest.py
```

会用桩件模拟 ComfyUI 的 `folder_paths`，覆盖：扫描索引、预览图读取与上传、类别 / 预设持久化、多类别标签、
schema v2→v3 迁移、LoRA 挪动后的自动认领、节点 A 的动态下拉与状态解析（v1 / v2 两种格式）、节点 B 的拼接顺序与分隔符。

## HTTP 接口

管理面板用的接口（与 ComfyUI 同源，无单独鉴权）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/lora_category_loader/api/state` | 类别 + LoRA + 预设全量视图 |
| POST | `/lora_category_loader/api/rescan` | 重新扫描 LoRA 目录 |
| POST | `/lora_category_loader/api/category` | 新建 / 修改类别 |
| POST | `/lora_category_loader/api/category/delete` | 删除类别 |
| POST | `/lora_category_loader/api/category/reorder` | 调整类别顺序 |
| POST | `/lora_category_loader/api/lora` | 保存单个 LoRA 的类别 / 强度 / 预设 |
| POST | `/lora_category_loader/api/lora/tag` | 加 / 减一个类别标签（`add` / `remove`，不动其他标签） |
| POST | `/lora_category_loader/api/lora/bulk` | 批量改标签（`add_category` / `remove_category`）或强度 |
| POST | `/lora_category_loader/api/autotag` | 按文件夹自动归类 |
| GET | `/lora_category_loader/api/preview?name=` | 预览图（本地文件或 302 到远端） |
| POST | `/lora_category_loader/api/preview/upload` | 上传预览图（multipart：`name` + `file`） |
| POST | `/lora_category_loader/api/preview/delete` | 删除预览图 |
